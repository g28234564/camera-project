# سامانه ثبت عکس با رضایت کاربر

## اجرا روی کامپیوتر
1. Python 3.10 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید:
   `python -m venv .venv`
3. فعال‌سازی محیط:
   - ویندوز: `.venv\Scripts\activate`
   - مک/لینوکس: `source .venv/bin/activate`
4. نصب وابستگی‌ها: `pip install -r requirements.txt`
5. متغیرهای محیطی `BOT_TOKEN` و `CHAT_ID` را تنظیم کنید.
6. اجرا: `python app.py`
7. برای دسترسی دوربین در مرورگر، سایت باید روی HTTPS باشد (به‌جز localhost).

## تنظیم تلگرام
- با BotFather یک ربات بسازید و توکن را دریافت کنید.
- به ربات پیام بدهید و شناسه عددی چت خود را در `CHAT_ID` قرار دهید.
- توکن را محرمانه نگه دارید و هرگز داخل کد سمت مرورگر قرار ندهید.

## نکته حریم خصوصی
این برنامه فقط پس از نمایش پیش‌نمایش دوربین و فشردن دکمه «ثبت و ارسال عکس» تصویر را می‌گیرد و به چت تلگرام تنظیم‌شده می‌فرستد. دسترسی دوربین از طریق مجوز خود مرورگر انجام می‌شود.
برای استفاده عمومی، سیاست نگهداری و حذف تصاویر را هم شفاف اعلام کنید.


## تنظیم ساده فایل محرمانه
- فایل `.env.example` را کپی کنید و نام کپی را دقیقاً `.env` بگذارید.
- مقدار `BOT_TOKEN` را در فایل `.env` با توکن BotFather جایگزین کنید.
- مقدار `CHAT_ID` از قبل برای شما تنظیم شده است: `8795132937`.
- فایل `.env` را برای کسی ارسال نکنید و در فضای عمومی منتشر نکنید.
